# PROJECT STATE

## Project objective

Build a reproducible and scientifically defensible Business Analytics framework for Swiss ski destinations, integrating resort structure, hotel overnight stays, Magic Pass adoption, and climate/snow information. The authoritative mission is `prompts/main_research_prompt.md`.

## Current phase

Checkpoints 1–3, the first treatment-unit review, the unmatched-label resolution, and initial capacity/climate integrations are complete. Checkpoints 4–5 are formally failed for causal and heterogeneous-effect modelling under the present design. Path C version 0.12 is implemented: current structural lift-cluster segmentation, nearest-current-member and nearest-reviewed-treated analogues, empirical support/OOD flags, min/median/max aggregation sensitivity, qualified point-container tourism context, separate Swiss municipality-point and harmonised Eurostat 2021 cross-border grid population context, qualified NPVM 2025 road/public-transport context with a complete geometric proxy audit, qualified current OFT/BAV public-transport-stop proximity, qualified current FEDRO/ASTRA national-road-axis proximity, an official winter-2026 scheduled public-transport journey context, a versioned current review of all 15 destination arrival nodes, and a same-pair diagnostic comparing distance with scheduled transit time. It is an exploratory prototype, not a causal or predictive uplift model; population radii are not visitor catchments, road-axis distance is not motorway access or route time, and door-to-lift walking and historical GTFS stability are not yet verified.

## Current model decision

- Municipality fixed effects: diagnostic panel exists, but causal treatment/control status is not ready.
- Staggered DiD/event study: not credible yet.
- Matching/synthetic control: rejected for causal use under the present exhausted donor design.
- K-means plus nearest analogues: selected for exploratory Path C with stability and OOD diagnostics.
- Causal forest, X-Learner, DR-Learner: unsupported by the effective treated sample.
- Gradient boosting/random forest: not run because no defensible cluster-level supervised target exists.
- Neural network: rejected; monthly repetition does not create independent resorts.

No causal estimate, CATE, uplift prediction, opportunity score, or business recommendation has been produced.

## Important methodological decisions

- Python remains the primary language; raw and external source responses are immutable.
- The existing lift clustering is a provisional reference layer and was not reconstructed.
- Resort listings, lift clusters, official Magic Pass destinations, reviewed destination units, and municipalities remain distinct units.
- A point's containing municipality is recorded only as `coordinate_container_only`; it is never promoted to tourism exposure.
- Membership events and destination-month rows remain causal-not-ready until treatment intensity/exposure, confounding, spillovers, and controls are approved.
- Crans-Montana's documented 2020-04-30 base-pass exit proves treatment cannot be assumed absorbing.
- Suppressed hotel values are missing, not zero, and are not imputed.
- Physically negative SLF snow-depth values are retained in raw evidence but set missing in derived metrics. Station proxies preserve distance/elevation diagnostics and never claim direct slope representation.
- SwissMetNet precipitation retains its official 06:00-to-06:00 UTC daily window. Weather anomalies use project-calculated 2013–2025 station/month references, not official climatological normals. Regional station proxies remain non-piste and causal-not-approved.
- Validation must remain grouped by destination/municipality and time.
- Path C uses the existing lift cluster as the least duplicated available entity, while retaining the warning that it is not a certified independent destination. Membership, hotel outcomes, snow vulnerability and geography are excluded from the three-feature structural clustering.
- Analogue opportunity and snow vulnerability remain separate dimensions. Qualified tourism, Swiss municipality-point and Eurostat cross-border grid population, NPVM zonal travel-time, current official stop-proximity, current FEDRO/ASTRA national-road-axis proximity and reviewed current scheduled-journey context are available. The same-pair comparison shows that distance and scheduled time are correlated but not interchangeable. Approved catchment-level tourism dependence and historically validated destination accessibility are still unavailable; strategic need remains incomplete and no composite ranking is authorised.
- Official population and hotel-intensity ratios are retained only as point-container context. They do not establish destination catchments, so the generic tourism-dependence field remains blank and no composite ranking is authorised.
- The Swiss population-threshold distances and radius totals use municipality representative points in EPSG:2056. A separate Eurostat 2021 grid supplies consistent Swiss/foreign one-kilometre cell-centroid totals; the two products are not combined because reference years and spatial allocation differ. Neither represents transport-network impedance, observed visitors or a destination catchment, so the generic accessibility score remains blank.
- NPVM travel times are assigned from exact listing-point traffic-zone containment where possible. High-alpine Swiss points outside the discontinuous zone polygons use only the nearest zone intersecting the same independently resolved current municipality; all 98 such links and distances are geometrically reconstructed. Fifty proxy-only clusters lack an internal exact-zone reference. The result is not live routing, rail-only access, a timetable, an arrival-node validation or a catchment, so it is never promoted to the generic accessibility score.
- Public-transport-stop proximity retains only official `VP`/`VPG` passenger stops. Train stations require official elementary mode code `B`; rack railway code `E` is not silently relabelled. Distances are straight-line from supplied listing points, not routes, timetable/frequency quality, seasonal service, valley-station access or catchments. All-mode nearest stops can be cableways or chairlifts, so the result is never promoted to the generic accessibility score.
- National-road proximity uses the official `Stammachsen` main-axis layer separately from the union of main, feeder, connection and ramp axes. The published schema contains no motorway-class or usable-entrance field, so these are current straight-line point-to-line diagnostics—not motorway access, a legal route, travel time, winter reliability or historical infrastructure—and are never promoted to the generic accessibility score.
- Scheduled public-transport journeys use checksum-verified GTFS Static, normalized Swiss base stop IDs, active service calendars, generic published transfers and explicit six-vehicle/eight-hour limits. Initial waiting and in-vehicle journey time remain separate. A weekday and Saturday snapshot does not represent real-time disruptions, fares, crowding, every seasonal day or historical service stability, so the measure is descriptive and never promoted to a causal accessibility feature.
- Destination arrival-node review requires an exact versioned component/stop match, bus/train capability, the component point's current municipality and a maximum 2.1 km point distance. The six village/local-centre fallbacks remain labelled as such. This review does not establish door-to-lift walking, historical node continuity or line stability.

## Known blockers and data gaps

1. Independent destination/domain definitions remain unresolved outside the 14 reviewed candidate units.
2. Active-season membership continuity is complete for the 14 reviewed units. Individual winter/summer modality is still unavailable for 2019/2020 and 2021/2022 because those publications do not provide a named modality list; this is a treatment-intensity gap, not a membership gap.
3. All 26 unmatched base-entry labels are classified for scope risk, but none has been promoted to an identity-equivalent causal mapping. Four officially documented Swiss destinations have no own row in the supplied directory, and Les Diablerets remains a resolved many-to-many overlap rather than a one-to-one identity.
4. Core-municipality proxies do not establish full tourism catchments. Network-wide point distance and same-destination distance bands expose proximity risk; NPVM 2025 adds zonal context; current OFT/BAV data add stop proximity; current ASTRA data add national-road-axis proximity; and winter-2026 GTFS adds scheduled origin-to-destination journeys. The ASTRA schema does not identify motorways or usable entrances. The 15 current arrival nodes pass the versioned descriptive review, but six are village/local-centre proxies and door-to-lift walking, hotel locations, historical travel times and visitor spillovers remain unresolved.
5. No full historical municipality-boundary harmonization has been implemented. The complete 2025 STATPOP universe is aligned to the 2026 snapshot through the seven identified identifier changes, but earlier outcome years retain their source municipality definitions.
6. Hotel capacity, official Swiss municipal population, harmonised Eurostat cross-border population, qualified snow/temperature/precipitation proxies, NPVM 2025 context, current OFT/BAV stop proximity, current FEDRO/ASTRA national-road-axis proximity and winter-2026 scheduled journeys are integrated. Historical anchor URLs are identified, but archive `robots.txt` prohibits automated retrieval of the 2018–2025 feeds; systematic snowmaking, explicit motorway-entrance access and catchment-level tourism dependence remain missing. The seven remote donor pairs now have complete-roster label checks and contemporaneous-shock review; exact competing-pass operator tariffs remain qualified but are no longer decision-critical because every pair is independently excluded.
7. Sixty resort-to-snow-station links have low spatial/elevation comparability. The alternative-SLF-station test is complete for the 15 reviewed components, but four have low agreement; an independent gridded sensitivity remains pending for snow, and alternative-station/gridded sensitivity remains pending for regional weather.
8. The 52-municipality post-scope apparent control pool and 404 provisional treatment-distance pairs remain screening outputs. The top-35 pre-trend shortlist is exhausted: distance deprioritises 28 pairs at or within 50 km and official-source review excludes all seven remote pairs for donor-specific shocks. Any future causal attempt requires a redesigned/broader donor strategy rather than promoting a current shortlist row.
9. The exact upstream source/version of the lift GPKG and retrieval dates of legacy extracts remain unknown.
10. The core Path C structural variables remain undated directory snapshots. Qualified municipal point-container intensity is available for 39 of 104 candidates, while Swiss and cross-border straight-line population, NPVM zonal travel time, usable current stop proximity and usable current national-road-axis proximity are available for all 104; road context is complete for 103. Current arrival-node review is complete only for the 11 reviewed treated destinations, not the 104 candidates; catchment-level tourism dependence, historical service accessibility and competing-pass status remain missing. Twenty-five candidates are strong extrapolations from the eight reviewed treated references. Aggregation sensitivity is explicit: only 11 candidates are stable on every recorded min/median/max criterion.

## Immediate next action

Strengthen Path C without turning it into a false uplift model: obtain the identified 2018–2025 GTFS anchor feeds manually or through an authorised channel before applying the same routing rules, and add explicit walking/access evidence if door-to-lift precision is required for the six village/local-centre arrival proxies. Cross-border population, current national-road-axis proximity, NPVM proxy geometry and the current distance–transit comparison are complete, while 50 proxy-only clusters still lack an exact-zone sensitivity reference. Next upgrade point-container ratios to defensible destination/catchment tourism dependence; audit competing-pass status; seek dated infrastructure snapshots; and add gridded snow/regional-weather sensitivities. A true motorway-access measure additionally requires explicit road-class and entrance data. A future causal redesign still requires a broader donor search and stronger exposure/confounder evidence. See reports 17–30 for the active architecture and limitations.
